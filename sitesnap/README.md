# SiteSnap – Photo organizer

A web app (PWA): live camera, tag photos with your own folders/subfolders/places, time + GPS + logo stamp, export as ZIP.
Data stays on the user's device. Works offline.

## Publish on GitHub Pages
1. Create a public repository and upload all files in this folder.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Open `https://<user>.github.io/<repo>/` (add the folder name if the files are in a subfolder).

## Install on phone
- iPhone: open in Safari → Share → Add to Home Screen.
- Android: open in Chrome → ⋮ → Install app.
- Allow camera and Location when asked.

## Update
Upload the new files over the old ones, then close and reopen the app once or twice.
